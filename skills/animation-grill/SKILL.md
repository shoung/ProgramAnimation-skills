# 動畫創作訪談

直接使用本技能時，先走套件的[啟動流程](../program-animation/references/startup.md)，在訪談前完成同一 AI agent session 的版本檢查與歡迎。若 `program-animation` 已執行開場，或正在等待此 session 的更新選擇，沿用該狀態。

## 怎麼問

先讀對話、委託資料及既有成片，只問創作者或委託人才知道、且答案會影響成片的事。初次訪談和交片後修改都採分輪問答，總題數與輪數依缺口決定。

- 同一輪可問多題，將目前能獨立回答的問題合併，用編號短句列出。只剩一個缺口時就問一題。需要前一題答案才能問清楚的問題，等答案明確後再問。
- 先請對方描述具體的回憶、畫面或偏好。遇到選擇困難，可給少量具體選項和一個有理由的建議，接受自由回答、不確定或由製作者代決。
- 收到答案後，按新的資訊檢查還有哪些會改變成片的決定。重要缺口已釐清或交由製作者決定時，就整理創作簡報或修改清單，交給對方確認。

## 第一次做片

從對方已說的細節切入。例如使用者說想拍一支給家人看的早餐店短片，這一輪可同時問兩題。

1. 看完後，你最希望家人記起外婆的哪一個動作？
2. 家人會用手機看，還是聚在一起用電視播？

若對方答「每天拉開鐵門」，下一輪再追問那個動作的聲音或細節。涉及回憶或事實時，把自己的猜測說成提議。按實際缺口從以下方向挑題。

- **目的與觀眾**：為誰而做？在哪個時刻會播放？看完後希望他們記得、感覺或做到什麼？
- **故事或內容**：哪個片段絕對要有？哪些人名、順序、用詞或經歷必須準確？抽象動畫也可以用一種情緒、一個變化或音樂段落作為主線。
- **觀看條件**：播在哪裡、觀眾怎麼拿螢幕、約有多久願意看？對方有明確的橫直式、時長、交付用途就記下來。
- **視聽偏好**：喜歡或討厭哪一段作品？具體是運鏡、節奏、聲音、細節密度，還是人物的表現？旁白由誰在對誰說？哪些地方需要留白或安靜？
- **執行界線**：區分「一定要做到」、「由你試著處理」及「還待本人補充」。解析度、編碼器、程式框架、採樣率等由製作者依用途決定。

資訊足以提出一版時，在對話寫一小段**創作簡報**，交代目的、觀眾、內容主線、長度與方向、聲音、必備細節和代決項目。邀請使用者確認這是否就是他想做的片子，然後停下來。收到同意後，將已確認簡報交回製片流程編寫劇本及分鏡。若對方修正，沿著有變動的部分繼續追問。

## 交片後修改

以目前交付版本為基準。先找出對方指的時間碼、畫面或台詞，再按上述規則追問「看到或聽到哪一刻感覺不對？」「改到什麼樣子你會覺得對？」能從對話定位的鏡頭，直接叫出鏡號或描述。把「高級一點」、「再有感情」等形容詞換成可觀察的差異。例：「你希望那句話說慢一點，還是說完之後，鏡頭多停在她手上？」有依據時提出自己的首選及理由。

把結果寫成**修改清單**。每項列出鏡號／時間碼、現在的表現、修改動作、如何判定改好，並交代會連動的聲畫與時長。再列出**保留項目**，例如原配色、音樂或已認可的鏡頭。請對方確認整張清單並等待明確同意。若先收到新的修改意見，更新清單並重新確認。同意後才交回製片流程動手。
