# 畫面內的文字

每張樣片用「燈塔」示範片名在該媒材中的做法。換題材時，可先取正式片名裡筆畫最密的幾個字，放進一個代表鏡頭，連同背景紋理一起縮到實際播放尺寸檢視。長字幕可承接字族、字色和底板，把筆畫上的顆粒或發光減淡，讓讀者在單鏡時間內讀完。

| 畫法 | 片名在畫面裡怎麼成立 | 用在較長的字句 |
|---|---|---|
| 層疊剪紙 | 深墨色粗黑體落在獨立米白紙牌，右下方有一層紙厚與投影。 | 延長紙牌、保留邊距，讓投影方向與場景紙層一致。 |
| 山水水墨 | 直行楷字旁留細款和朱印，筆邊有微小起伏與乾墨。 | 增加行距、避開濃墨，細字用較實的墨。 |
| 浮世繪木版 | 朱紅直式題簽刻白字，以深色邊線和窄副簽呼應版畫輪廓。 | 依字數增長題簽，細筆與底色間保留足夠反差。 |
| 青綠金箋 | 墨褐楷字直接題在金地的留白，配朱印。 | 用深墨承接主標，避開青綠重色及金粉亮斑。 |
| 黏土微縮 | 厚白字帶暖色側面，筆緣朝同一光源受光，像另捏的一件物件。 | 續用暖白與圓邊，降低擠出厚度以免相鄰的字黏在一起。 |
| 孔版套色 | 使用深色主版、偏移的洋紅與藍墨及紙白留邊，字心仍能辨識。 | 內文集中在主墨版，降低錯版距離。 |
| 莫比烏斯式清線 | 深墨字排進淡黃漫畫旁白框，硬邊和右下陰影承接畫面的清楚輪廓。 | 依閱讀順序安排旁白框，留出人物和鏡頭動作的位置。 |
| 復古工程圖 | 鉛褐楷字配細而疏排的西文，與圖上的尺寸線、圖說共用墨色。 | 用圖說層級及細引線定位，縮圖核對線條和字的分別。 |
| 等角場景模型 | 低彩度細襯線字置於模型旁的留白，像展示台上的說明。 | 維持留白與一致對齊，標註跟著模型時避開遮擋。 |
| 粒子點雲 | 暖白細字以疏密不同的發光微粒構成，保留連續筆形。 | 避開掃動光束的最亮段，小字收斂外光並提高筆心密度。 |
| 1-bit 抖動 | 暗底銘牌配象牙色粗字，題名與邊線也只用場景的兩個色值。 | 用實色字和整像素邊界，讓網點留在字框外。 |
| 厚塗油畫 | 暖白襯線字有斜向的乾刷和筆脊，暗暖底色托起受光筆畫。 | 保留明暗對比，隨字級縮小筆觸，避免短撇與點消失。 |

## 套用到自己的文字

從技能目錄執行以下範例。將 `--font` 換成含完整片名的本機字型路徑。

```sh
python3 scripts/render.py --style ink-wash --title '山城夜雨' --font '/path/to/full-TC-font.ttf' --png /tmp/title.png
python3 scripts/render.py --style one-bit --title '海岸' --seconds 2 --video /tmp/coast.mp4
```

在自己的渲染器裡，可參照 [lettering.py](../scripts/lettering.py) 的字形遮罩、印刷偏移與材質合成，或在 960 × 540 的 Pillow RGB 畫布上呼叫 `letter(image, style, title, font_path)`。橫直式和字幕排版依實際鏡頭另定。傳入空片名可輸出無題字畫面。燈塔用的英文副標、邊款與印刷樣例以示範片名觸發；更換片名時可另寫作品自己的副標。

套件內附 Noto Sans TC、Noto Serif TC 與霞鶩文楷 TC 的八字子集「燈塔海岸風景研究」，依 SIL Open Font License 分發。拓展字集可使用同系列完整版。[Noto 字型授權](../assets/type/OFL.txt) · [霞鶩文楷授權](../assets/type/OFL-WenKai.txt)
