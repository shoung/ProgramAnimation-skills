# 純程式動畫製作

用使用者的語言工作。從圖形、字排、角色、場景、光影到運動都由程式生成。依故事選擇 2D、3D、排版、圖解、抽象、敘事或其組合。附帶的燈塔只用於比較畫法。劇本與分鏡直接顯示在對話中。

## 1. 問清楚，再寫稿

使用同套件的 [animation-grill](../animation-grill/SKILL.md) 進行初次訪談。先確認創作簡報，收到同意後才編劇本與分鏡。若簡報已在本次對話中明確確認，從該處接續。

在對話中呈現可直接審讀的一版。

- **劇本**寫出片名或工作名、主線、開頭／轉折／結尾、實際台詞或旁白。純視覺片用動作與聲音節奏敘事。
- **分鏡**逐鏡列時間區間、畫面主體及動作、構圖／鏡頭運動、聲音與剪接點。核對總時長，朗讀旁白估計是否塞得進各鏡。
- **我代為決定的事項**說明哪些視覺或聽覺選擇是製作者提出的，以及對這支片的作用。技術實作由製作者決定。
- 邀請使用者審稿，提示稿件定案後會選視覺美術風格。若收到修改，先更新稿件，等使用者同意再進下一步。

## 2. 用真實預覽選風格

從[風格目錄](references/styles.md)依定案劇本選三款。若確實只有兩款貼合，可推薦兩款並說明取捨。用圖片語法直接展示每款**個別 PNG**，將目錄中的相對路徑解析為安裝位置的絕對路徑；若對話介面支援附件呈現，可用其圖片預覽。總覽適合讓使用者自行瀏覽。每款說明：

1. 哪個鏡頭或敘事任務特別適合這款。
2. 對這支片可能造成什麼問題，例如細字遇到網點、低光鏡頭丟失層次。
3. 製作時會調哪個具體元素，例如粒子密度、線距、色盤或光束速度。

請對方選定一款或確認具體的混合方式，再開始做影片。若偏好還模糊，可以用已確認的一鏡做等構圖的小樣協助選擇。

## 3. 按劇本製作

自己選合適的技術路線，可重用樣本畫法、改寫或從零開發。依確認的內容建立時間軸、場景與程序化音軌。以明確時間／影格索引驅動畫面，讓指定鏡頭能重算。使用者有指定聲音素材、旁白或靜音段時照其要求；其他需要的旁白、配樂與音效均用程式合成。合成旁白**之前**先完成下一節的讀音校對。

[製作與品管](references/production.md)載有執行方式、通用逐幀檢查器、瀏覽器恢復方式、聲音方案和交付驗證。範例引擎和尺寸只用來展示畫法；垂直影片要為直幅重新構圖。

## 4. 逐幀驗片，附實際交付資訊

- 每一幀在送入編碼器前讀回真實像素，檢查透明、空白、近單色及該鏡頭預期主體。故意安排的全黑／全白影格須有精確的時間範圍及預期顏色。遇到意外空白，恢復渲染器，回到同一幀重畫並再次驗證。連續失敗要停在該幀診斷，修好後才交片。
- 配音前逐句校對多音字、專有名詞、數字及單位，把畫面原文與送給 TTS 的念法分開。有疑義時記下採用讀法與原因。合成後回聽高風險詞，對照最終剪輯回填時間碼。
- 實際解碼最終影片，核對畫面數、尺寸比例、聲軌、時長、剪接連續性、字幕可讀性及混音。交付可播放的檔案或連結、片長及有意義的驗證結果。有未定讀音時逐一標出「時間碼、詞語、暫用讀法、要聽哪裡」。如有未能驗證的事項就指明。

## 5. 收到修改意見

回到 [animation-grill 的修改訪談](../animation-grill/SKILL.md)。先將變更與保留項目整理給使用者，等使用者同意該版清單後才改。保留原交付版，重算受影響鏡頭和聲軌，重新核對剪接、時間碼及最終輸出。交付新版時逐項對照清單。
